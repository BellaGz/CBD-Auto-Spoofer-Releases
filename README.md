# CBD Auto Spoofer — Downloads

A Windows app + Roblox Studio plugin that re-uploads the animations and audio a
Roblox place uses to **your own account or group**, then updates the asset IDs in
your open Studio session — for re-owning the assets in a place you own or bought.

## Download

Grab the latest **`AutoSploof.exe`** from the [Releases page](../../releases/latest).

The app installs the Studio plugin for you on first launch. You'll need a license
key to open it.

## Requirements

- Windows 10 / 11
- Roblox Studio
- An Open Cloud API key (asset read + write) or your account cookie
- A license key
